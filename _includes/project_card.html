{% comment %} _includes/project_card.html =========================== Reusable project card for the documentation hub landing page. CRITICAL — WHY THIS HEADER IS A LIQUID COMMENT AND NOT AN HTML COMMENT Liquid runs before the browser ever sees the file, and it does not know what an HTML comment is. A literal include tag written inside is therefore still executed: the include pulls in its own file, which executes the example again, forever. The build does not error — it recurses until the process runs out of memory and `jekyll build` simply hangs. Any documentation header in _includes/ or _layouts/ that contains {% raw %}{%{% endraw %} or {% raw %}{{{% endraw %} must use a Liquid comment block, and any tag shown as an example must additionally be wrapped in {% raw %}{% raw %}{% endraw %}. THIS CARD RENDERS NO LITERAL TEXT OF ITS OWN Every visible string is a KEY into _data/i18n.yml, resolved for the language the current page declares in its front matter. That is why the parameters are named *_key rather than carrying the text itself: one include call produces the English and the German card. USAGE (from _includes/page_body.html): {% raw %}{%- include project_card.html label_key="card.label.project" status_key="se.status" title_key="se.title" desc_key="se.desc" docs_url="https://keglev.github.io/stockease/" repo_url="https://github.com/Keglev/stockease" badges="Java 21, Spring Boot 3, Angular" -%}{% endraw %} PARAMETERS label_key (required) i18n key for the type pill, e.g. card.label.ai title_key (required) i18n key for the project title desc_key (required) i18n key for the description paragraph status_key (optional) i18n key for the status line. Renders with a green indicator dot via the .status class. demo_url (optional) URL of a running deployment. Rendered first. docs_url (optional) URL of the generated documentation. repo_url (optional) Primary repository URL. repo2_url (optional) Secondary repository URL (e.g. a split front end). Its presence switches the label to the plural key and stacks both links. badges (optional) Comma-separated technology list. Product names, deliberately NOT translated. label_class (optional) Variant class for the type pill: `project` (default) or `ai`. See main.css section 11. extra_class (optional) Extra class on .card, e.g. `card-centered` for a card left alone in the final grid row. NOTES - All external links open in a new tab with rel="noopener". - This include does not emit the wrapping .grid element; the caller is responsible for placing it inside
