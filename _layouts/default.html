{% comment %} _layouts/default.html ===================== Main layout template for the Project Documentation Hub. Applied to all pages via front matter: layout: default TEMPLATE ENGINE: Jekyll + Liquid HOSTING: GitHub Pages (static, no server-side processing) BILINGUAL MODEL --------------- Each language is a real, separately indexable page rendered from the SAME template and the SAME string catalogue (_data/i18n.yml): / -> index.md (lang: en) default /de/ -> de/index.md (lang: de) The language switch in the header is a plain between the two URLs. No JavaScript is involved: a recruiter can share the German URL, and search engines index both versions (see rel="alternate" hreflang below). Every page must declare `lang: en` or `lang: de` in its front matter. Strings are read as: {% raw %}{{ site.data.i18n[page.lang]['some.key'] }}{% endraw %} THEMING ------- . Dark is the default and is written into the markup, so a browser with JavaScript disabled still gets a complete, intentional theme. Tokens for both themes live in assets/css/main.css. The inline boot script below applies the stored preference BEFORE the stylesheet is requested, so a user who chose the light theme never sees a dark frame flash first. It must stay inline and must stay above the stylesheet link; moving it into theme.js reintroduces the flash.
