{% comment %} _layouts/default.html ===================== Main layout template for the Project Documentation Hub. Applied to all pages via front matter: layout: default TEMPLATE ENGINE: Jekyll + Liquid HOSTING: GitHub Pages (static, no server-side processing) BILINGUAL MODEL --------------- Each language is a real, separately indexable page rendered from the SAME template and the SAME string catalogue (_data/i18n.yml): / -> index.md (lang: en) default /de/ -> de/index.md (lang: de) The language switch in the header is a plain between the two URLs. No JavaScript is involved: a recruiter can share the German URL, and search engines index both versions (see rel="alternate" hreflang below). Every page must declare `lang: en` or `lang: de` in its front matter. Strings are read as: {% raw %}{{ site.data.i18n[page.lang]['some.key'] }}{% endraw %} STRUCTURE --------- meta, SEO, hreflang, stylesheet .site-header Sticky bar: brand and language switch .wrapper Centered content container (max 860px)
Page content injected by Jekyll .site-footer Copyright and contact links ADDING A NEW PAGE ----------------- 1. Create the English file in the repository root and the German file under /de/ with the same name. 2. Front matter on both: --- layout: default lang: en # or: de permalink: /path/ # or: /de/path/ --- 3.
